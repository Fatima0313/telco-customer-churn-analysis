# Telco Customer Churn Analysis

## Business Problem
Why are customers leaving the telecom company?

## Objective
Identify churn patterns, high-risk customer segments,
and factors associated with customer churn.

## Tools
SQL | Python | Power BI | Machine Learning

## Analysis
- Churn by contract
- Churn by tenure
- Churn by internet service
- Churn by customer services
- Customer risk segmentation

## Machine Learning
Model: Logistic Regression

Accuracy: 80.6%
ROC-AUC: 84.2%
Churn Recall: 56%

## Key Findings
- Overall churn: 26.5%
- Month-to-month customers showed substantially higher churn.
- Churn was concentrated among newer customers.
- Fiber-optic month-to-month customers were a particularly high-risk segment.
- ML high-risk group had 71.8% actual churn.
